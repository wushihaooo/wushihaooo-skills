# 病例级数字病理 MIL：输入和公平性

这些规则适用于以病例为预测单位的数字病理实验。研究者明确同意的偏离标为“探索性”，不混入遵循这些规则的公平比较。

## 两级聚合

各方法（包括基线）都要适配下面的两级结构，不能以原论文按切片训练为由破坏病例级公平性。

- 每张切片的全部有效 patch → 切片内 MIL → 一个切片表征；同病例的全部切片表征 → 跨切片 attention/池化 → 病例预测。
- 切片不作为彼此独立的训练样本，也不用切片预测概率的平均代替第二级聚合。
- 划分、训练、验证、测试与指标都以病例为单位；同一患者有多个病例时，患者不跨分区。
- 多模态方法的视觉部分同样遵守两级结构；文本在病例级或明确说明的层级融合，不改变视觉输入。

## 全量输入

- train/val/test 都读取每张切片的全部有效 patch：不随机抽样、不定额取样、不 top-k 预筛、不截断。
- 所有比较方法使用同一批病例、切片、patch 和视觉特征。
- 每个 epoch 每个训练病例恰好出现一次，不用有放回的类别均衡采样；类别不平衡用损失加权等方法处理。
- 显存优化只用不丢 patch 的等价方法（分块、重算、流式、梯度累积）。局部 softmax 后直接平均不等价于完整 attention；梯度累积要核对损失归一化。
- TransMIL 的 Nyström 等近似属于模型本身的定义，不能称为与完整 attention 等价的显存优化。
- CLAM 在完整 bag 上做主聚合、只为辅助损失挑选 top/bottom 实例时，要说明这一点；不能借此删减主聚合的输入。padding/mask 不能变成真实 patch 或被重复计数。

## 训练代码中的自动检查

每次运行自动执行，不另存检查记录：

1. 病例/患者 ID、标签、切片映射有效，没有跨分区的病例或患者。
2. 没有空切片；缺失或损坏的输入明确处理，不能某个方法悄悄跳过。
3. 加载器实际读取的 patch 数与清单一致，没有隐藏的截断。
4. 所有方法读取的病例、切片、patch 和划分一致。
5. 每个 epoch 结束时，每个训练病例恰好出现一次。

## 冒烟的边界

冒烟可以只用少量真实病例，但每个选中的病例仍须保留全部切片和全部有效 patch，并至少包含最大的病例；不能为了通过冒烟而截断 patch。冒烟结果不作为正式性能证据。
