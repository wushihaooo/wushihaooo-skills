# 病例级数字病理 MIL：输入和公平性

这些规则适用于以病例为预测单位的数字病理实验；非病理任务不强行套用。用户在当前项目明确批准的偏离必须另立、标记为探索性协议，不得混入遵循这些规则的公平比较。

## 两级表征聚合

在步骤1协议中确定实际基线清单。常见候选是 Mean/Std pooling、ABMIL、CLAM-SB、TransMIL；已有 SCOPE 或文本融合方法时列为相应对照。根据任务与预算让用户确认实际选择，不自动继承所有历史模型。各方法都要适配下面的两级结构，不能以原论文按切片训练为由破坏病例级公平性。

- 每张切片的全部有效 patch → 切片内 MIL → 一个切片表征；同病例的全部切片表征 → 跨切片 attention/池化 → 病例预测。端到端指这两级聚合相连，不要求默认微调图像特征提取器。
- 切片不得作为彼此独立的训练样本，切片预测概率平均不得代替第二级表征聚合。
- 划分、训练、验证、测试、bootstrap 与指标均以病例为单位。若同患者多病例，划分与重采样还须保留患者聚类，保证患者不跨分区；说明病例级估计与患者相关性处理。
- 多模态视觉主干同样遵守两级结构。文本在病例级或明确记录的层级融合；不能改变视觉输入集合。

## 全量输入

- train/val/test 都读取每张切片的全部有效 patch。不随机抽样、不定额取样、不 top-k 输入预筛、不固定上限截断；缓存大小不得变成输入上限。
- 所有比较方法使用同一病例、切片边界、patch 集合及视觉特征。文本等额外输入在相应对照中明确标记，并安排视觉单模态与简单融合对照。
- 每 epoch 每训练病例恰好出现一次；不使用类别均衡有放回重采样。失衡采用不改变病例覆盖率的损失权重等方法。
- 显存优化只用不丢实例的等价分块、重算、流式或梯度累积。局部 softmax 后随意平均不等价于完整 attention；流式 softmax 需正确合并归一化和加权和。梯度累积应核对损失归一化及更新频率，不能声称任何累积都等价。
- 对跨 patch attention 不得用相互独立的切块代替全局关系。TransMIL 自身的 Nyström 等近似应作为模型定义明示，不能叫作与密集 attention 数学等价的显存优化。
- CLAM 若在完整 bag 上计算主 MIL 并仅为辅助实例损失挑选 top/bottom 实例，需披露该语义；不能把其改为删减主 MIL 输入。padding/mask 不得变成真实 patch 或产生重复计数。
- SCOPE 邻域只在同一张切片内部构建，覆盖该切片全部有效 patch。SCOPE 通过邻域访问的每个 patch 也必须提供给基线。

## 训练前的自动审计断言

1. 患者/病例 ID、标签、切片映射有效，无跨分区病例及患者；预处理拟合不访问验证或测试标签。
2. 无空有效切片、无失配坐标或非法邻居索引；缺失/损坏输入明确处理，不能某方法悄悄跳过。
3. 完整清单中的实例数与加载器实际读取数一致，主聚合覆盖所有真实 patch，模型与缓存没有隐藏截断。
4. 所有方法的病例、切片、patch ID/集合、特征及分区清单哈希一致。哈希相同只是输入文件一致的证据，还需实际消费路径覆盖检查。
5. 所有 SCOPE 邻居的 `slide_id` 与中心 patch 相同，且覆盖全部有效中心 patch。
6. epoch 结束核对训练病例一次且仅一次；病例覆盖、切片数、每片 patch 数、总量与审计清单匹配。

保存病例级分区、患者映射、每病例切片数、每片 patch 数、总 patch 数、输入清单/哈希、随机种子、聚合方式、掩码语义、等价分块验证。所有报告明确两级聚合、全 patch、是否使用等价分块及病例级统计；输入改变则原比较失效，需要新协议和匹配基线。

## 冒烟的例外边界

可用小型合成 bag 检查张量/梯度，用少量选定的真实病例测量时间和峰值资源；每个被选真实病例仍须保留全部切片、每张切片全部有效 patch，并至少覆盖最长切片和最大病例。冒烟子集不作为正式性能证据，不作为正式训练数据替代；不能为通过 smoke 随手截到1,024 patch。
