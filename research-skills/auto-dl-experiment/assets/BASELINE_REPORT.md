# 基线实验报告

数据集二（1228 例）；开发集 982 例，固定测试集 246 例，开发集内五折。以下为待执行配置，正式训练尚未开始。

## 公共超参数

| 参数 | 设置 |
|---|---|
| 随机种子 | 42；五折各自初始化，不做多种子平均 |
| 优化器 | AdamW，学习率 3e-4，权重衰减 1e-4；无学习率调度 |
| Dropout | 0.25 |
| 有效 batch size | 16 个病例，逐病例累积梯度；末批按实际病例数归一化 |
| 训练上限与早停 | 最多 30 epochs；验证 AUC 连续 5 轮无改善即停，min_delta=0；并列选较早轮 |
| 损失函数 | Focal Loss：gamma=2，两类 alpha=1 |
| 类别采样 | 训练病例权重为类别数量的倒数，有放回抽取 N 次/轮（N=训练病例数）；采样流 seed=42+epoch |
| 梯度裁剪 | 范数上限 5 |
| 病例聚合 | 切片表征投影为 64 维，再做跨切片门控注意力；注意力隐层 32 维 |
| 计算设置 | 全 patch 两级聚合；FP32、关闭 TF32，使用等价梯度检查点重算 |
| 评价 | 阈值 0.5；每折按验证 AUC 选轮，同一 checkpoint 分别报告验证与测试指标，汇总五折均值 ± 标准差 |

加权有放回采样为已授权的探索性偏离；测试队列曾用于历史研究。

## 方法特有超参数

| 方法 | 设置 |
|---|---|
| Mean/Std | patch 投影 256 维，均值与标准差拼接为 512 维；标准差使用 sqrt(var+1e-5)，var 分母为 patch 数 |
| ABMIL | patch 表征 512 维，门控注意力隐层 256 维 |
| CLAM-SB | 同 ABMIL；1 个注意力分支，实例 k=8，辅助 CE 权重 0.3，不做 subtyping |
| CLAM-MB | 同 CLAM-SB，但使用 2 个类别注意力分支，分别在病例级聚合 |
| TransMIL | 表征 512 维；2 层、8 heads、256 landmarks、伪逆迭代 6 次；PPEG 卷积核 7/5/3 |

CLAM 的 top/bottom-k 仅用于辅助损失，不删主聚合输入；小 bag 的 k 不超过 patch 数的一半。

## 基线实验结果

各指标为五折均值 ± 标准差（ddof=1），不是合并预测或模型集成结果；标准差不是置信区间。阈值 0.5；Recall、Precision、F1 针对复发类，混淆矩阵为五折计数均值，顺序 [[TN, FP], [FN, TP]]。
